Критерии Домашнее задание 5 

Важно для всех пунктов: у всех заданий обязательно должна быть EDA (минимум 4 графика)

Задание 5 считается выполненным, если сделан полностью один из пунктов ниже:

1)Сравнение VAE vs COLES vs Classic OD (IFOrest, DBSCAN, etc.) на датасете №1
    а) Загружен датасет №1 и разделен на тест и трейн
    б) Есть обученный VAE и посчитана метрика для теста
    в) Получены эмбеддинги COLES и обучен (V)AE и посчитана метрика для теста
    г) Получены эмбеддинги COLES и обучен один из классических алгоритмов и посчитана метрика для теста
    д) Проведено сравнение и написан вывод

2) Сравнить качество работы unsupervised детекторов аномалий на датасете №2
    а) Загружен датасет №2 и разделен на тест (не менее 20% от исходной выборки) и трейн
    б) Есть обученные unsupervised детекторы аномалий (не менее 6) и посчитаны метрика для теста (тест должен быть единый для всех алгоритмов)
    в) Сделать вывод метрики для всех алгоритмов на тестовой выборке в единую табличку
    г) Проведено сравнение и написан вывод 

3) Разбор на предмет аномалий датасета №3
    а) Загружен датасет №3 и разделен на тест (не менее 20% от размеченной выборки) и трейн
    б) Использован один из алгоритмов из семинара
    в) Есть обученный алгоритм и посчитана метрика на тесте
    г) Получен ROC AUC не меньше 0.9 на тесте

4) Сравнить PYOD vs PYTOD (10 алгоритмов) на датасете №1
    а) Загружен датасет №1 и разделен на тест
    б) Есть обученные алгоритмы из библиотеки PYOD, посчитана скорость обучения и метрика для теста
    в) Есть обученные аналогичные алгоритмы из библиотеки PYTOD, посчитана скорость обучения и метрика для теста
    г) Собрать скорость и метрики для всех алгоритмов в единую табличку
    д) Проведено сравнение и написан вывод 


*) для заданий со словом «сравнить» нужна статзачимость
